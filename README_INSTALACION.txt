AP TIME — INSTALACIÓN
=====================

1. Copia la carpeta AP_TIME dentro de:
   C:\xampp\htdocs\

2. Enciende Apache y MySQL desde XAMPP.

3. Abre phpMyAdmin y ejecuta:
   database/ap_time.sql

4. Abre la tienda:
   http://localhost/AP_TIME/

5. Panel administrador:
   http://localhost/AP_TIME/admin/login.php

   Usuario inicial: admin
   Contraseña inicial: APtime2026!

FUNCIONES
=========
- Agregar relojes.
- Agregar varias fotografías por reloj.
- Elegir fotografía principal.
- Editar nombre, precio y modalidad.
- Modalidades: Contra entrega / Bajo encargo.
- Publicar u ocultar productos.
- Eliminar productos y sus fotografías.
- Catálogo público con búsqueda y filtro.
- Ficha individual con galería de fotografías.
- Consulta por WhatsApp.

IMPORTANTE
==========
- Las fotografías nuevas se guardan en uploads/products/.
- La primera fotografía seleccionada al crear un reloj queda como principal.
- El proyecto está preparado para PHP + MySQL con XAMPP.
- El código fuente fue ordenado en líneas verticales para facilitar edición y mantenimiento.
